# DNS هوشمند PS5

DNS برای باز شدن بازی‌های تحریم‌شده روی PS5 (و بقیه‌ی کنسول‌ها و کامپیوتر)، با پنل وب چندکاربره برای فروش اشتراک.

## نحوه‌ی کار
- **سرور ایران**: DNS و پنل. در دسترس کاربران است، پینگ پایینی دارد و DNS آن دستکاری نمی‌شود.
- **سرور خارج**: ترافیک بازی‌ها از سرور ایران با تانل **VLESS Reality** به این سرور می‌آید و از اینجا به سرور بازی می‌رود.
- فقط دامنه‌های لیست از تانل رد می‌شوند و بقیه‌ی اینترنت مستقیم است.
- فقط کاربرانی که در پنل تعریف شده‌اند می‌توانند از DNS استفاده کنند.

## نصب با یک خط (Ubuntu، با کاربر root)

</div>

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/borhanslm/ps5-smartdns/main/install.sh)
```

<div dir="rtl">

1. اول روی **سرور خارج** اجرا کنید و گزینه‌ی `1` را بزنید. در پایان یک لینک `ps5dns://...` می‌دهد که باید کپی‌اش کنید.
2. بعد روی **سرور ایران** اجرا کنید، گزینه‌ی `2` را بزنید و لینک را paste کنید. در پایان آدرس پنل و یوزر و پسورد را نشان می‌دهد.

اگر فقط یک سرور خارج دارید، گزینه‌ی `3` را بزنید.

اگر `raw.githubusercontent.com` روی سرور باز نشد:

</div>

```bash
git clone https://github.com/borhanslm/ps5-smartdns.git /opt/ps5-smartdns && bash /opt/ps5-smartdns/install.sh
```

## پنل و کاربران
- در پنل کاربر بسازید (تعداد روز و حداکثر تعداد IP) و با **Copy link** لینک را برایش بفرستید.
- کاربر لینک را با همان اینترنتی که کنسول به آن وصل است باز می‌کند و **Register this network** را می‌زند. هر وقت IP او عوض شد، دوباره لینک را باز می‌کند.
- تمدید، غیرفعال کردن، حذف کاربر و ویرایش لیست دامنه‌ها همه از داخل پنل انجام می‌شود.

## تنظیم PS5
Settings ← Network ← Settings ← Set Up Internet Connection ← اتصال شما ← Advanced Settings ←
DNS را روی Manual بگذارید و Primary و Secondary را **IP سرور ایران** وارد کنید.

## دستورات
`ps5dns login` · `ps5dns reset-password` · `ps5dns link` · `ps5dns logs` · `ps5dns update` · `ps5dns uninstall`

## محدودیت
فقط ترافیک وب (TCP 80/443) از تانل رد می‌شود. ترافیک UDP خود بازی آنلاین مستقیم می‌رود. دانلود بازی‌ها هم عمداً از تانل رد نمی‌شود.
